# Contributing

Thanks for helping improve Vulnora AI.

1. Open an issue describing the problem or proposed feature.
2. Keep changes defensive and consent-based.
3. Add or update tests for changed behaviour.
4. Never add credentials, API keys, personal data, or real customer scan reports.
5. Run `python -m pytest -q` before submitting a pull request.

Please avoid adding exploit automation, brute-force, stealth, or unrestricted internet-wide scanning features.
