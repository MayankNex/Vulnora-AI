# Security Policy

## Reporting a vulnerability

Please do not publish sensitive details in a public issue. Use GitHub's private vulnerability reporting feature for this repository if it is enabled. Include:
- A concise description and impact
- Steps to reproduce in a safe, non-destructive test environment
- Affected commit or version
- Suggested mitigation, if known

Do not test against systems you do not own or have permission to assess.

## Scope

Vulnora is a passive website configuration checker. Security reports about this repository, its dependencies, or its own application are in scope. Findings from third-party websites scanned with Vulnora are not automatically vulnerabilities in Vulnora.
